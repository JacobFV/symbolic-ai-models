# lessons/

`findings/` records what is true about the *subject*. This records what is true
about **how we go wrong** — the mistakes, their shapes, and what now guards each
one.

It is separate from `RESEARCH_LOG.md`'s "what was believed and is false" because
that table lists *claims* that died. This lists the *mechanisms* that killed
them, which is the reusable part. A claim is wrong once; a mechanism keeps
producing wrong claims until something structural stops it.

The bar for an entry: a real mistake that was actually made here, what it cost,
and — where one exists — the guard that makes it not recur. An entry with no
guard is a standing hazard and should say so.
